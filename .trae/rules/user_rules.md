# 项目开发规则

## 1. 模块化开发与测试

项目应该按照模块化的方式开发，每个模块/函数都有对应的测试代码。新增或修改代码时需要确保测试用例能够覆盖到新增或修改的代码，运行测试用例确保代码质量。

## 2. 功能添加流程

增加一个功能后，除了生成自动测试代码，默认将新增的功能添加到菜单中，提供用户手动确认测试的入口。

## 3. 本地化约定

除非指定，否则图形界面中的文字默认使用中文。

## 4. 代码规范
HTML：结构清晰，标签语义化（如使⽤ header 、 section 等标签），缩进规范；
CSS：类名规范，样式简洁，避免冗余，可复⽤；
JS：模块化拆分，函数命名规范（语义化），注释清晰，避免全局变量污染，处理异常情况；
整体代码：⽆语法错误，可直接运⾏，⻚⾯⽆明显布局错乱。
