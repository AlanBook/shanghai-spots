# 上海景点展示网页系统

## 项目简介

这是一个基于原生前端技术栈开发的上海景点展示与导览系统。系统采用响应式瀑布流布局，提供多维度的景点信息展示，并集成了百度地图 API 提供智能路线规划。项目采用模块化设计，具备高可定制性和出色的用户交互体验（如多套海派文化主题皮肤无缝切换）。

👉 **[在线预览 (GitHub Pages)](https://alanbook.github.io/shanghai-spots/)**

## 技术栈

- **HTML5**: 语义化页面结构
- **CSS3**: 响应式瀑布流布局、CSS 变量管理、渐变与玻璃拟态效果
- **JavaScript (ES6+)**: 原生 JS 实现的复杂交互、状态管理与 API 异步调用
- **JSON**: 静态数据存储与配置解耦
- **Baidu Map API**: 第三方地图服务（智能路线规划、导航调起）

## 核心功能特性 (Features)

本项目的所有交互逻辑均集中在 `js/app.js` 中，实现了以下核心功能：

### 1. 动态瀑布流展示
- **自适应渲染**：根据设备宽度和图片比例动态计算卡片高度。
- **智能列分配**：采用贪心算法（始终插入最短列），保证三列布局的视觉平衡。

### 2. 多维度搜索与筛选
- **实时防抖搜索**：支持对景点名称和城市名称的模糊匹配，带有 300ms 防抖处理。
- **动态标签筛选**：从数据源动态提取并生成所有唯一标签，支持**多选组合过滤**。
- **联动排序**：支持按评分（高→低/低→高）或按价格排序，搜索与筛选状态实时联动。
- **一键重置**：提供快速清除筛选条件和全部重置功能。

### 3. 主题皮肤切换
- **海派文化主题**：内置“本原模式”、“经典复古风”和“摩登都市风”三套高质量 UI 皮肤。
- **状态持久化**：使用 `localStorage` 记住用户的皮肤偏好，刷新页面不丢失。

### 4. 深度交互体验
- **详情弹窗 (Modal)**：点击卡片可查看包含历史沿革、游玩提示等丰富信息的模态框。
- **本地收藏夹**：支持在卡片和弹窗内对景点进行收藏，状态通过 `localStorage` 跨会话同步。
- **外部链接**：一键跳转至百度百科获取更多背景知识。

### 5. 路线规划系统 (基于百度地图 API)
- **手动路线设计**：用户可自定义选择最多 7 个景点，生成特定顺序的导览路线。
- **智能路线规划**：调用百度地图 `DrivingRoute` 服务，根据用户勾选的多个景点地理位置，自动计算并优化出一条最短/最合理的游玩路线。
- **一键导航**：在生成的路线结果中，可直接调起百度地图 Web/App 端进行全流程导航。

## 运行方式

由于项目采用纯前端技术栈且包含外部数据请求 (`fetch`)，请使用本地服务器运行，以避免浏览器的跨域 (CORS) 限制。

```bash
# 方法一：使用 Python 内置服务器
python -m http.server 5500

# 方法二：使用 Node.js 的 http-server
npx http-server -p 5500
```
运行后在浏览器访问 `http://localhost:5500` 即可。

## 开发规则

本项目遵循严格的模块化与规范化开发，详见 [user_rules.md](.trae/rules/user_rules.md)。

- **模块化**：`app.js` 采用单例对象 `App` 封装，各功能按方法严格拆分。
- **本地化**：图形界面中的文字默认使用中文。
- **进度管理**：目前已完成 `v0.1` 至 `v0.4`（自主探索与功能拓展）的全部规划。
