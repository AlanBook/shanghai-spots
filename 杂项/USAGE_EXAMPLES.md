# 🎯 智能路线规划功能使用示例

## 示例1: 选择2个景点（起点-终点）

### 操作步骤

1. 进入"智能路线规划模式"
2. 选择景点：
   - ☑️ 外滩 (s1)
   - ☑️ 东方明珠 (s2)
3. 点击"确定选择"
4. 选择出行方式：🚗 驾车
5. 查看路线规划结果

### 预期结果

```
起点: 外滩
终点: 东方明珠
距离: 约2公里
预计时间: 约10分钟
```

### 使用场景

适合简单的两点之间的路线规划，如：
- 酒店到景点
- 景点到餐厅
- 家到景点

## 示例7: 智能路线优化

### 操作步骤

1. 进入"智能路线规划模式"
2. 选择景点（顺序随意）：
   - ☑️ 上海科技馆 (s21)
   - ☑️ 外滩 (s1)
   - ☑️ 东方明珠 (s2)
   - ☑️ 上海中心 (s3)
3. 点击"确定选择"
4. 系统自动优化路线顺序
5. 查看优化后的路线

### 预期结果

系统会根据距离和时间自动优化访问顺序，例如：

```
优化前顺序:
1. 上海科技馆
2. 外滩
3. 东方明珠
4. 上海中心

优化后顺序:
1. 外滩 (起点)
2. 东方明珠
3. 上海中心
4. 上海科技馆 (终点)
```

### 优势

- 🚀 减少总行程时间
- 🚗 避免重复路线
- ⏱️ 更高效的行程安排

## 💡 使用技巧

### 1. 景点选择技巧

- **按地理位置选择**：选择相邻区域的景点
- **按时间安排**：考虑景点开放时间
- **按兴趣爱好**：选择感兴趣的景点类型

### 2. 出行方式选择

| 场景 | 推荐方式 | 原因 |
|------|---------|------|
| 市区短途 | 🚶 步行 | 灵活方便 |
| 市区中距离 | 🚌 公交 | 经济实惠 |
| 郊区长距离 | 🚗 驾车 | 节省时间 |
| 休闲娱乐 | 🚲 骑行 | 健康环保 |

### 3. 路线优化技巧

- **起点选择**：选择距离最近的景点作为起点
- **终点选择**：选择距离最远的景点作为终点
- **途经点**：选择中间位置的景点作为途经点

### 4. 时间规划技巧

- **预留时间**：每个景点预留充足时间
- **交通时间**：考虑景点间的交通时间
- **休息时间**：安排适当的休息时间

## ❓ 常见问题

### Q: 为什么路线没有优化？

A: 请检查：
1. 是否选择了至少3个景点
2. 是否选择了驾车模式（只有驾车支持途经点）
3. 百度地图API是否正常加载

### Q: 如何查看详细的路线信息？

A: 点击"在百度地图中查看详细路线"按钮，即可在百度地图中查看：

- 完整路线图
- 详细导航
- 交通状况
- 预计时间

### Q: 可以修改路线顺序吗？

A: 可以在百度地图中手动调整途经点顺序

### Q: 如何保存路线？

A: 在百度地图中点击"分享路线"即可保存或分享
