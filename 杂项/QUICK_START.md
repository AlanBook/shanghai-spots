# 🚀 快速开始指南

## 5分钟快速配置和使用智能路线规划功能

### 步骤1: 获取百度地图AK (2分钟)

1. 访问 [百度地图开放平台](https://lbsyun.baidu.com/)
2. 登录您的百度账号
3. 进入【控制台】→【我的应用】
4. 点击【创建应用】
   - 应用类型：**浏览器端**
   - 白名单：`*`（开发阶段）
5. 复制生成的AK（访问密钥）

### 步骤2: 配置AK (1分钟)

**方法A - 编辑 config.js（推荐）**

编辑 `config.js` 文件，将第10行的 `YOUR_AK_HERE` 替换为您的AK：

```javascript
const AppConfig = {
    baiduMapAK: '你的实际AK',  // ← 改这里
    enableSmartRoute: true
};
```

**方法B - 运行配置脚本**

```bash
node setup-ak.js
```

然后按照提示输入您的AK。

### 步骤3: 测试配置 (1分钟)

运行测试脚本：

```bash
node test-smart-route.js
```

应该看到：

```
✅ 所有测试通过！
```

### 步骤4: 使用功能 (1分钟)

1. 打开 `index.html`
2. 点击"🤖 智能路线规划模式"
3. 选择至少2个景点（点击checkbox）
4. 点击"确定选择"
5. 选择出行方式（推荐"🚗 驾车"）
6. 在百度地图中查看详细路线

## 🎯 完成！

## ❓ 常见问题

**Q: API加载失败？**  
A: 检查AK配置是否正确，网络连接是否正常

**Q: 坐标不准确？**  
A: 系统会自动转换，无需手动处理

**Q: 途经点不可用？**  
A: 途经点功能仅在驾车模式下可用
